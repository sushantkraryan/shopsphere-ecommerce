\# ShopSphere — E-Commerce Backend



A production-style e-commerce REST API built with Spring Boot, demonstrating layered

architecture, JWT-based security, transactional business logic, and industry-standard

testing and deployment practices.



\## Tech Stack



\- \*\*Language:\*\* Java 21

\- \*\*Framework:\*\* Spring Boot 3.x

\- \*\*Database:\*\* MySQL 8

\- \*\*Build Tool:\*\* Maven

\- \*\*ORM:\*\* Spring Data JPA (Hibernate)



\## Status



🚧 Actively under development. See commit history for incremental progress.



\## Getting Started



\### Prerequisites

\- JDK 21

\- Maven 3.9+

\- MySQL 8 running locally



\### Run locally

\\`\\`\\`bash

cd backend

./mvnw spring-boot:run

\\`\\`\\`



The API will be available at `http://localhost:8080`.
